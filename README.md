# VaultFlow · 个人资产盘点与收支规划

当前先开发和验证**网页版**。适合每隔一两个月集中盘点资产、回看期间收支、安排未来收入支出的个人使用方式。

## 当前主流程

1. 账户页添加现金、投资、负债和固定资产账户。
2. 单独更新账户余额会新增节点，图表在资产趋势页集中查看；输入框支持加减算式。点击「保存首次盘点」，保存完整账户余额、汇率和备注。
3. 期间手工记账或导入账单；历史导入不改当前余额。
4. 点击「开始新盘点」，批量填写实际余额，保留每次节点及待解释差额。
5. 资产趋势页查看历史节点，添加未来收入和支出计划，查看预计结余。
6. 设置页导出 JSON 备份；覆盖恢复保留盘点与计划。合并导入按记录 ID 去重，存在历史分歧时拒绝自动合并。

**小镇 / RPG 暂时搁置**：当前网页不提供入口，不加载地图、游戏渲染及回忆同步模块。旧代码与浏览器内的数据保留；旧 `/town/*`、`/rpg/*` 链接回到资产大盘。

## 运行与验证

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5174/ 。浏览器数据按来源隔离，改变主机名或端口会进入另一份本地存储；清除浏览器数据前务必导出备份。

```bash
node scripts/test-asset-checkpoints.mjs
node scripts/test-finance-persistence.mjs
npm run build
```

`build` 只生成网页资源。仓库保留 Electron 相关代码和脚本，目前不作为这轮开发与验收范围，也不代表已经打包或发布。

## 数据与边界

- 账本与偏好保存于浏览器 localStorage；不是在线账户服务。
- 修改账户和汇率不会重写已有盘点。旧版倒推数据保存在 `legacyAssetSnapshots`，不能当成真实盘点。
- 当前网页的 JSON 备份包含资产账本、历史盘点及未来计划，不包含暂停的小镇照片库、完整回忆数据或 API 密钥设置。
- OCR 仅在用户配置并主动使用时请求第三方服务；不能把整个项目描述成“任何数据都不会离开设备”。
- 发现现有浏览器账本损坏时停止初始化，不用空数据覆盖；写入失败会显示提示，可导出当前 JSON。
- 同一账本的盘点使用相同基准币种；收支不完整时，待解释差额需要人工核对。

使用规则见 [资产盘点与规划](docs/资产盘点与规划.md)。历史 PRD、GTM 和小镇文档保留作参考，其中版本节奏和产品定位不代表当前执行计划。
