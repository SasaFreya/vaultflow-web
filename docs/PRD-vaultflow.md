> 版本：1.0.0-beta.1 · 文档日期：2026-07-09 · 状态：Beta 内测

## 1. Summary

VaultFlow 是一款本地优先的个人资产可视化工具，帮助用户在本机管理账户、导入多平台账单、追踪净资产趋势，并通过「人生小镇」将财务数据与生活回忆结合。本文档定义 v1 Beta 至 v1.0 正式版的产品范围、成功指标与发布计划。

## 3. Background

### 3.1 背景

越来越多用户同时使用微信、支付宝、银行卡和基金账户管理资产，但主流记账 App 要求注册登录并将数据上传云端。部分用户（注重隐私、技术敏感）希望数据完全留在本机，同时获得清晰的净资产可视化。

VaultFlow 起源于「个人资产可视化仪表盘」项目，在资产核心之上叠加了人生小镇 RPG 层，把记账从「填表」变成「经营自己的人生小镇」。

### 3.2 为什么是现在

- Electron + Vite 技术栈成熟，单人可交付跨平台桌面端
- 微信/支付宝账单导出已普及，本地解析可行
- AI 可选接入（百炼 DashScope）可降低回忆撰写门槛，但不强制依赖云服务
- Beta 内测包（`1.0.0-beta.1`）已可分发 dmg/exe

### 3.3 新近可能

- 本地 LLM 与 OCR 成本下降，可选增强导入与回忆能力
- PWA + Service Worker 让 Web 版具备通知深链能力

## 4. Objective

### 4.1 产品目标

让用户在 **10 秒内** 完成一笔手动记账，在 **15 分钟内** 完成首次智能导入并看到净资产趋势曲线，且全程数据不离开本机。

### 4.2 对公司/用户的价值

- **用户**：隐私可控、多源账单聚合、趋势可预测、体验有温度
- **产品**：验证 Local-first 财务工具 + 游戏化人生记录的市场需求

### 4.3 战略对齐

- 核心定位：**隐私优先的个人财务中枢**
- 差异化：**资产数据 × 人生回忆** 双轨，而非纯记账或纯日记
- v1 明确不接第三方存储 API（除用户自配 AI/OCR Key）

### 4.4 Key Results（SMART）

| KR | 目标 | 时间框 |
|----|------|--------|
| KR1 | 内测用户 ≥ 30 人完成完整测试流程（账户→导入→趋势） | Beta 4 周内 |
| KR2 | 微信/支付宝导入一次成功率 ≥ 85% | Beta 期间持续 |
| KR3 | 7 日留存 ≥ 40% | Beta 第 2 批用户 |
| KR4 | 关键路径崩溃率 < 1%（启动、导入、保存） | 正式版前 |
| KR5 | 收集 ≥ 20 条可行动反馈并闭环 ≥ 60% | Beta 全程 |

## 5. Market Segment(s)

### 5.1 主细分市场：隐私敏感型个人理财用户

**Job to be Done**：当我想掌握自己的净资产变化时，我希望能把各平台账单汇总到一处、看到趋势，同时不让任何公司拿到我的原始财务数据。

**特征**：
- 25–40 岁，有一线城市生活经验
- 使用 2+ 支付/银行账户
- 对云同步持谨慎态度，愿意接受略高的使用摩擦（手动备份）
- 对「好看、有仪式感」的 UI 有偏好

**约束**：
- 不愿为记账 App 付高额订阅（v1 免费内测）
- 可接受未签名 App 的安装步骤
- 中文环境为主，账单格式以国内平台为主

### 5.2 次级细分市场：人生记录爱好者

**Job to be Done**：当我想记录生活片段时，我希望消费数据和回忆能自动关联，而不是分散在记账 App 和备忘录里。

**特征**：
- 已有写日记/拍照片习惯
- 愿意探索人生小镇、微场景等游戏化入口
- 可选配置 AI Key 辅助写回忆

### 5.3 非目标用户（v1 不做）

- 需要实时多设备同步的家庭/情侣账本
- 企业财务、发票管理
- 投资理财荐股类需求

## 6. Value Proposition(s)

### 6.1 主价值主张

**「你的资产，只住在你的电脑里。」**

| JTBD 要素 | 内容 |
|-----------|------|
| **Who** | 注重隐私的个人用户 |
| **Why** | 不想把账单交给云端 |
| **What before** | 多 App 分散、手动 Excel、或忍受云记账 |
| **How** | 本地 Electron App + 多格式智能导入 + 可视化仪表盘 |
| **What after** | 一屏看清净资产、趋势、预算与目标 |
| **Alternatives** | 随手记、MoneyWiz、自建 Notion/Excel |

**「记账不只是数字，是你的人生地图。」**

- 五域生态（职/身/心/社/家）把消费与回忆投射到外出地图
- 微场景内写回忆、挂照片，无需跳出游戏感界面
- 可选 AI 草稿降低写作门槛

### 6.3 价值曲线差异点

| 维度 | 竞品常见 | VaultFlow |
|------|----------|-----------|
| 数据隐私 | 中 | 高（本地 only） |
| 导入覆盖 | 中 | 高（微信/支付宝/银行 PDF） |
| 情感体验 | 低 | 高（小镇/RPG） |
| 上手速度 | 高 | 中（需安装+导入） |
| 跨设备同步 | 高 | 低（v1 无） |

## 7. Solution

### 7.1 信息架构 / 用户流

```
启动 → [PIN 锁屏?] → 侧边栏导航
  ├── 银行（Dashboard）— 净资产总览
  ├── 记账（Transactions）— 手动录入 / 智能导入
  ├── 账户（Accounts）
  ├── 分析（Analysis）— 趋势/预算/目标入口
  ├── 日历（Calendar）— 现金流事件
  ├── 人生小镇（/town）— Hub 地图
  │     ├── 外出地图（/town/explore）— 五域生态
  │     └── 人生馆（/town/loft）— 回忆/小屋
  └── 设置（Settings）— 基准日、AI Key、隐私、关于
```

### 7.2 Key Features

#### F1 — 账户与净资产管理
- 支持现金/投资/负债/固定资产四类账户
- 多币种 + 汇率换算（CNY 基准）
- 负债账户余额自动规范为负值
- 删除账户时检测关联交易并阻止

#### F2 — 记账与智能导入
- 手动记账：收入/支出、分类、关联账户
- 智能导入：微信 `.xlsx`、支付宝 `.csv`（GBK 兼容）、招商/农行等 `.pdf`
- 批量解析、预览确认后导入
- 导入不改动账户当前余额；趋势由交易反推

#### F3 — 可视化与预测
- 仪表盘：净资产、资产结构饼图、月度趋势、分类支出
- 趋势页：历史净资产曲线（基于基准日 + 流水反推）
- 日历页：工资/还款/提醒事件，月末净资产预测
- 预算页：分类限额 inline 编辑
- 目标页：储蓄目标与分配模式

#### F4 — 隐私与安全
- PIN 锁屏（本地 hash，会话级解锁）
- 隐私遮罩模式（金额打码）
- 数据仅存本机 `Documents/VaultFlow/data.json`

#### F5 — 人生小镇（RPG 层）
- Hub 地图：银行/心愿树/日历塔/人生馆/外出地图等建筑入口
- 外出地图：五域 Pin + 热力 + Pixi 粒子/runner
- 微场景：框内交互、写回忆、照片墙（IndexedDB）、可选 AIGC 壁纸
- 生态浮层：时间轴联动地图高亮
- 通知深链：Electron / PWA 点击通知直达微场景

#### F6 — 可选 AI（用户自配）
- 百炼 DashScope Key：回忆草稿、视觉理解
- 无 Key 时功能降级，不阻断主流程

#### F7 — 导入/导出
- JSON 全量导出/导入
- 数据备份：复制 `Documents/VaultFlow/` 文件夹

### 7.3 Technology

| 层 | 技术 |
|----|------|
| UI | React 19, TypeScript, Tailwind, Radix UI, Framer Motion |
| 图表 | Recharts |
| 游戏层 | PixiJS 8, Three.js (部分) |
| 路由 | react-router-dom HashRouter |
| 桌面 | Electron 35, electron-builder |

| 银行 PDF | Python 脚本 `scripts/bank_pdf_parser.py`（Electron spawn） |

- 移动端原生 App
