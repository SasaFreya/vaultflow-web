## 一、粉白小镇 · 萌系Q版社交乐园

### 参考图片
- 换装界面：https://kimi-web-img.moonshot.cn/img/img.duotegame.com/28b141d5f870388d288d1835894a14e7454f0af0.jpeg
- 抽奖界面：https://kimi-web-img.moonshot.cn/img/img4.example.com/676502c60564f2bd14fa85d6247544ef6bddcdc8.png

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 高饱和马卡龙色系：樱花粉、薄荷绿、淡紫、奶油黄。背景常用淡紫/淡蓝渐变，营造梦幻感。 |
| **造型** | 2.5头身Q版角色，大头小身，眼睛占脸1/3，无棱角，全部圆滚滚。 |
| **UI** | 卡片式布局，大圆角（16px+），边框带浅色描边+内发光，按钮有立体凸起感。 |
| **字体** | 圆润无衬线体，标题带手写感或星星/爱心装饰。 |
| **动效** | Hover时弹跳/摇晃，换装时旋转展示，抽奖时光效粒子。 |
| **氛围** | 治愈、童真、社交展示欲，强调「被看见」和「装扮自我」。 |

### 可提取的设计元素
- **圆角卡片**：所有容器圆角≥16px，杜绝直角
- **糖果色板**：#FFB6C1（粉）#98FB98（绿）#DDA0DD（紫）#FFFACD（黄）
- **拟物图标**：给功能模块加「表情」和「小配件」（如钱包=抱着金币的小熊）
- **微交互动画**：hover放大1.1倍 + 弹性缓动

### 对应人生小系统模块
> **心愿墙、个人主页、小镇装饰** —— 用粉白小镇的萌系表达欲，让用户愿意「装扮」自己的数字空间。

## 二、泰拉瑞亚 · 16-bit像素沙盒

### 参考图片
- 城堡草原：https://kimi-web-img.moonshot.cn/img/img.3dmgame.com/2e394da46dc08ece8edfcf6fd96d58beb59b1137.jpg
- 沙漠像素：https://kimi-web-img.moonshot.cn/img/img.3dmgame.com/db226357c4b9f6dd72b3a36ffe6a409346d4ef1b.jpg

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 有限色板（16-256色），高对比色块，暗色调+亮色点缀。不同生态区有专属调色板（森林绿、沙漠金、雪地蓝、地狱红）。 |
| **造型** | 纯像素点阵，2D横版，方块化地形，角色3-4头身Q版但轮廓硬朗。 |
| **UI** | 极简HUD，物品栏像素图标，血条蓝条用色块填充，无圆角，全是直角像素。 |
| **字体** | 像素字体（Pixel Font），或系统字体加像素化渲染。 |
| **动效** | 逐帧像素动画，水流动、旗帜飘动、火把闪烁，强调「物理感」。 |
| **氛围** | 探索未知、自由改造、征服世界，玩家是「造物主」。 |

### 可提取的设计元素
- **分层色彩**：不同功能层级用不同生态区配色（浅层=明亮，深层=暗色）
- **像素图标**：功能图标用16×16或32×32像素画，而非矢量图标
- **解锁迷雾**：未开启功能用「阴影/迷雾」覆盖，随使用逐渐点亮
- **色块进度条**：不用渐变，用纯色块堆叠表示进度

### 对应人生小系统模块
> **心愿矿层、功能解锁路径** —— 用泰拉瑞亚的「分层探索感」，让心愿从浅到深像挖矿一样有阶梯。

## 三、田园小镇 · 精致像素田园

### 参考图片
- 完整农场：https://kimi-web-img.moonshot.cn/img/img.3dmgame.com/5c07d8af60ae8fa035af987492ff29803e6a9898.jpg
- 农场全景：https://kimi-web-img.moonshot.cn/img/img1.gamersky.com/2de65c1162b514f65b03edbcb9252fa462d398f6.jpg

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 四季色谱系统：春（嫩绿+淡粉+天蓝）→ 夏（浓绿+金黄）→ 秋（橙黄+红棕+低饱和黄绿）→ 冬（蓝白+灰）。每季分初期/盛期/后期，共12种渐变。 |
| **造型** | 俯视角固定地图，16-bit精度，角色表情细腻（虽然只有几个像素点），场景层次丰富（前景/中景/背景）。 |
| **UI** | 木质纹理边框，背包格子系统，对话框带角色头像，日历系统醒目。 |
| **字体** | 像素字体，但比泰拉瑞亚更柔和，带一点手写感。 |
| **动效** | 昼夜光影变化，四季植被变色，角色行走逐帧，天气粒子（雨/雪/落叶）。 |
| **氛围** | 温馨、慢节奏、归属感，世界在「呼吸」，玩家是「农场主」而非「访客」。 |

### 可提取的设计元素
- **四季换肤**：系统按真实季节自动切换主题色（春粉/夏绿/秋橙/冬蓝）
- **时间呼吸**：晨昏光影变化提示用户（早晨=暖黄，深夜=深蓝）
- **日程仪式感**：每日首次打开显示「今日天气+宜忌」，像小镇起床看电视
- **木质纹理**：边框用木纹质感，增加温度

### 对应人生小系统模块
> **日历、人生时间轴、小镇背景** —— 用小镇的「时间呼吸感」，让人生系统随四季变化，每天打开有仪式感。

## 四、火柴人世界 · 极简手绘涂鸦

### 参考图片
- 游戏画面：https://kimi-web-img.moonshot.cn/img/img.anfensi.com/ff68e9189e06d8cdcdde47ae403e6f29d5fd4ce7.jpg

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 黑白为主，单色点缀（红/蓝），大量留白，背景几乎空白。 |
| **造型** | 线条勾勒，一个圆+五条线=人物，无面部细节，无透视，纯扁平。 |
| **UI** | 极简到近乎没有，血条/进度条是纯色长条，按钮是线框。 |
| **字体** | 无衬线粗体，或手写体，字号极大。 |
| **动效** | 夸张动态（肢体拉伸、旋转、爆炸），强调「打击感」和「爽快感」。 |
| **氛围** | 纯粹、幽默、直接，没有任何干扰信息，一眼看到核心。 |

### 可提取的设计元素
- **信息极简**：仪表盘只留核心数字，删除一切装饰
- **线条图标**：用2px线条勾勒图标，而非填充色块
- **大量留白**：数据卡片之间留足呼吸空间
- **夸张反馈**：操作后有夸张动画（如数字弹跳、全屏震动）

### 对应人生小系统模块
> **资产仪表盘、数据总览** —— 用火柴人的「极简直接」，让核心资产数据一眼可见，不被图表淹没。

## 五、无尽冬日 · 末日冰雪写实

### 参考图片
- 冰原重建：https://kimi-web-img.moonshot.cn/img/image.52pk.com/25200b435833b1470a34a28385bc0c7160661918.png
- 战斗界面：https://kimi-web-img.moonshot.cn/img/img.picxiaobai.com/8bb2d8196c4ff7c7787ff155e7767ead4a5fc72d.jpg

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 冷蓝白（冰雪）+ 暖橙（火光）强对比，低饱和整体，高亮点缀。温度越低越偏蓝，安全区偏暖。 |
| **造型** | 写实比例，厚重材质（木头/石头/金属），斜45度视角，建筑有积雪覆盖细节。 |
| **UI** | 重度信息覆盖，顶部资源栏如汽车仪表盘，底部建筑卡片带价格，倒计时醒目。 |
| **字体** | 粗体无衬线，数字极大，紧急信息用红色+闪烁。 |
| **动效** | 火焰跳动、雪花飘落、建造进度条、温度数字实时变化。 |
| **氛围** | 压迫感、生存焦虑、策略权衡，信息=生命线。 |

### 可提取的设计元素
- **冷暖对比**：资产健康用暖色，风险预警用冷色（蓝=危险，反直觉但醒目）
- **仪表盘式数据**：核心数字像汽车仪表盘一样大且直观
- **倒计时/进度压迫**：重要操作带时间压力视觉（如预算剩余天数）
- **材质厚重**：重要卡片用毛玻璃/深色底，增加「分量感」

### 对应人生小系统模块
> **资产健康预警、预算管理、风险提醒** —— 用无尽冬日的「生存指标感」，让资产状态像温度一样直观可感。

## 六、时光杂货店 · 复古像素+手绘怀旧

### 参考图片
- 游戏封面：https://kimi-web-img.moonshot.cn/img/rs.1.gaoshouyou.com/4833748fb81492c3054d6006df8278100ad72abf.jpg

### 视觉DNA拆解
| 维度 | 具体特征 |
|------|---------|
| **色彩** | 暖黄滤镜，90年代怀旧色谱：旧报纸黄、复古红、军绿、搪瓷白。整体像老照片。 |
| **造型** | 手绘+像素混合，人物有写实比例但带柔和边缘，建筑有年代细节（斑驳木架、老式收音机、搪瓷杯）。 |
| **UI** | 木质货架式布局，商品卡片像摆在货架上，收银机按钮感，老电视雪花屏转场。 |
| **字体** | 复古印刷体/仿宋/手写黑板字，标题带做旧效果。 |
| **动效** | 货架补货动画，顾客进出，钱币叮当，磁带转动。 |
| **氛围** | 怀旧、温情、市井烟火，每件物品背后有故事。 |

### 可提取的设计元素
- **暖黄滤镜**：主背景用 #FFF8E7 或 #F5F0E6（旧纸张色），比纯白更护眼有温度
- **做旧细节**：边框加1px深色描边+轻微内阴影，模拟老式木框
- **物品叙事**：每个功能模块用「物品」隐喻（心愿=种子，资产=存钱罐，人生=相册）
- **年代道具**：时间轴用磁带、老照片、邮戳等视觉元素

### 对应人生小系统模块
> **人生故事线、时间轴、回忆相册、小镇模块** —— 用时光杂货店的「怀旧叙事感」，让人生事件像老物件一样有温度。

## 八、人生小系统风格融合建议

### 主风格定位
> **「粉白小镇萌系 + 时光杂货店怀旧暖调」** 的混合路线

### 各模块风格分配

| 模块 | 主参考 | 辅参考 | 具体做法 |
|------|--------|--------|---------|
| **小镇地图** | 粉白小镇 | 小镇 | 2.5D俯视角，圆顶建筑，马卡龙色，四季换背景色 |
| **资产仪表盘** | 无尽冬日 | 火柴人 | 顶部大数字仪表盘，核心数据冷暖对比，极简卡片 |
| **人生时间轴** | 时光杂货店 | 小镇 | 横向卷轴，老照片节点，四季背景，木质边框 |
| **心愿系统** | 泰拉瑞亚 | 粉白小镇 | 三层矿层结构，解锁迷雾，完成时撒花庆祝 |
| **日历** | 小镇 | 时光杂货店 | 四季日历28格，木质纹理，今日高亮呼吸灯 |
| **全局UI** | 粉白小镇 | 时光杂货店 | 圆角16px，暖黄背景，1px深色描边，圆润字体 |

### 核心色彩规范（直接给Cursor）
```css
:root {
  /* 背景 */
  --bg-primary: #FFF8E7;      /* 主背景：暖黄旧纸 */
  --bg-card: #FFFFFF;          /* 卡片：纯白 */
  --bg-dark: #2D2D2D;          /* 深色模式：炭灰 */

  /* 强调色 */
  --accent-primary: #FF8A80;   /* 主按钮：珊瑚粉 */
  --accent-secondary: #81D4FA; /* 次要：天空蓝 */
  --accent-success: #A5D6A7;   /* 成功：薄荷绿 */
  --accent-warning: #FFCC80;   /* 警告：暖橙 */
  --accent-danger: #EF9A9A;    /* 危险：淡红 */

  /* 文字 */
  --text-primary: #424242;     /* 主文字：深灰 */
  --text-secondary: #9E9E9E;   /* 次要：中灰 */
  --text-light: #FFFFFF;       /* 反白 */

  /* 边框与阴影 */
  --border-color: #E0E0E0;
  --shadow-card: 0 2px 8px rgba(0,0,0,0.08);
  --shadow-elevated: 0 4px 12px rgba(0,0,0,0.1);

  /* 圆角 */
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-xl: 24px; /* 全圆角按钮 */

  /* 四季主题（自动切换） */
  --spring: #A5D6A7;  /* 春：薄荷绿 */
  --summer: #81D4FA;  /* 夏：天空蓝 */
  --autumn: #FFCC80;  /* 秋：暖橙 */
  --winter: #B3E5FC;  /* 冬：冰蓝 */
}
```

### 字体规范
- **标题**：系统默认无衬线（PingFang SC / Segoe UI / -apple-system），font-weight: 600
- **正文**：同上，font-weight: 400，line-height: 1.6
- **数字**：等宽字体（Roboto Mono / SF Mono / Courier），金额/进度用等宽对齐

### 动画规范（Framer Motion / CSS）
```css
/* Hover 弹性放大 */
.building:hover {
  transform: scale(1.1);
  transition: transform 200ms cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹性 */
}

/* 页面切换滑入 */
.page-enter {
  animation: slideIn 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* 数字滚动 */
.number-roll {
  transition: all 800ms ease-out;
}

/* 呼吸灯（今日提醒） */
@keyframes breathe {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.6; }
}
.breathe {
  animation: breathe 2s ease-in-out infinite;
}

/* 撒花庆祝（心愿完成） */
@keyframes confetti {
  0% { transform: translateY(0) rotate(0); opacity: 1; }
  100% { transform: translateY(-100px) rotate(360deg); opacity: 0; }
}
```
