# 资产盘点与未来规划

## 使用流程

1. 在账户页建立账户，首次点击「保存首次盘点」，补全所有余额。
2. 平时记账或导入账单；导入账单不改变当前余额。
3. 下次点击「开始新盘点」，批量填写今天的真实余额，保存为新节点。同一天可以保存多个节点。
4. 展开节点查看当时账户明细、收入、支出与待解释差额。在资产趋势页填写未来收支计划，查看每月预计结余和净资产。

## 数据边界

- `assetCheckpoints` 是用户明确保存的盘点，包含账户副本、日期、保存时间、基准币种、汇率、备注，以及保存时已记录的流水 ID。
- 盘点保存时同步当前余额，不生成虚构收支。修改账户、增删流水、修改汇率均不改写已有盘点。
- 期间收支按上次盘点日期之后至本次日期的已记录流水核对。同一天新加入的流水单独计入。首次盘点没有期间差额。
- 待解释差额 = 本次净资产 - 上次净资产 - 已记录收入 + 已记录支出。可能包含投资波动、汇率、账户增减或漏记账，不自动归为收入。
- 核对结果是保存时的记录；后补历史流水只改变实时收支统计，不重写旧节点。
- 已被最新盘点吸收的手工流水，删除时不撤销真实盘点余额；尚未盘点的手工流水仍会回滚其余额影响。CSV 流水添加和删除均不改余额。
- 预测以当前账户净资产为起点（已包含手工余额更新及已入账流水），再从明天起累加未来计划。计划不影响真实账本；日历提醒作为独立视角，不重复叠加。
- 金额使用规划设置中的基准币种。节点间须使用相同基准币种，以避免将不同单位直接比较；汇率会随节点保存。

## 历史兼容

旧版 `assetSnapshots` 是倒推数据，无法还原真实账户盘点。首次加载时移到 `legacyAssetSnapshots`，随 JSON 备份保留，不作为真实历史展示。新的 `assetSnapshots` 只从明确保存的盘点派生，不再按流水重建。

旧时已经被覆盖、且未备份的账户余额无法恢复，需要从现在保存首次盘点。

## 单账户节点、历史补录与余额算式

- 编辑一个账户的余额后，点击「保存余额节点」即新增单账户记录，不必补全其他账户；趋势页的「各账户趋势」展示较上次／最早节点的变化，展开可查历次余额。
- 单账户趋势统一读取 `accountBalanceHistory` 与整体盘点内的账户明细。旧账户第一次修改时，若尚无任何节点，会先保留修改前的余额，明确标注为升级时保留的基线，不伪造旧日期。
- 支持选择过去日期补录已核实的余额；单账户及整体盘点的历史补录都不覆盖今天的账户余额。新记录按日期排序，已有节点内容不变。
- 余额输入支持数字、加减和括号，例如 `1000+200-35.5`，实时显示结果；内部用整数分计算，保存数值，不执行输入代码。不完整算式或空余额会显示具体账户提示。
- 已保存的旧版估算趋势现在可以在账户页单独展开查看；不当成真实盘点，也不能恢复旧版本从未保存过的每次账户编辑。
- 资产趋势和综合分析页共用「两个节点之间」区间分析：可选整体盘点起止节点，查看资产变化、实际收支、待解释差额、账户变化与支出分类。区间收支按当前账单重新计算，补账会更新分析，不改写历史盘点。
- 单账户记录和整体盘点是两种粒度：单独修改一个账户不冒充所有账户同日已核实的完整盘点；整体趋势和整体规划继续以完整盘点为资产锚点。


## 趋势页切换

- 账户页不再常驻趋势图，只负责填写余额与保存节点，并提供「查看各账户趋势」入口。
- 资产趋势页默认「大盘趋势」，可切换「各账户趋势」和「资产构成」。每次只挂载当前视图，离开后不继续渲染隐藏图表。
- 各账户视图默认展示全部账户，支持筛选单个账户；整体盘点与单账户节点继续沿用原记录，不迁移、不删除。
- 资产构成用环形饼图展示当前余额或指定历史盘点，可按账户／类别分组。资产与负债分别计算占比；空余额、零余额不做扇区，负资产另作说明，不把不同含义的数值混为一个圆饼。


## 现金流日历与真实趋势联动

- 大盘趋势默认只显示已保存的真实盘点。可自主勾选「显示现金流日历预测」或「显示手动收支计划预测」，两种场景分别显示虚线，不相互叠加。
- 日历场景按具体事件日期更新，支持每月重复事件与月底短月适配；今天及以前的事件不重复计入，打开／关闭预测均不修改账户或历史。
- 预测从当前填写的账户净资产出发，单账户更新也会反映在预测起点中。尚无整体盘点时仍可预览，但不会伪造真实历史。
- 工资增加净资产，支出减少净资产；还款本金同时减少现金与负债，对净资产中性。预测摘要另列还款与现金净流入；利息、手续费请另记为支出。
- 修正了重复事件在起始日期之前被展开的问题；已有的无来源旧副本不会自动删除。
