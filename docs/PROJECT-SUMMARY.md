# VaultFlow 一页项目摘要

> 版本 `1.0.0-beta.1` · 更新 2026-07-09 · Local-first 个人资产可视化

---

## 是什么

**VaultFlow** 是一款 **本地优先** 的个人资产可视化桌面应用。用户在本机录入账户、导入微信/支付宝/银行流水，查看净资产趋势、预算、目标与现金流预测；同时通过 **「人生小镇」** 把记账数据与生活回忆（职/身/心/社/家五域）以 RPG 式界面串联，降低「记账=枯燥表格」的心理门槛。

| 维度 | 内容 |
|------|------|
| **产品形态** | Electron 桌面端（macOS / Windows）+ 可选 Web/PWA |
| **数据策略** | 默认不上传服务器；数据存 `~/Documents/VaultFlow/`（桌面）或 localStorage（浏览器） |
| **当前阶段** | Beta 内测，未代码签名 |
| **技术栈** | React 19 + TypeScript + Vite + Electron + PixiJS + Recharts |

---

## 解决什么问题

| 痛点 | VaultFlow 的做法 |
|------|------------------|
| 记账 App 要登录、数据上云 | 纯本地存储，用户完全掌控 |
| 多平台账单格式不一 | 智能导入：微信 xlsx、支付宝 csv、招商/农行 pdf |
| 只有数字没有「人生感」 | 人生小镇 + 外出地图 + 微场景，把消费/回忆投射到五域生态 |
| 资产趋势难还原 | 基准日 + 历史流水反推月度净资产曲线 |
| 敏感金额在公共场合暴露 | 隐私遮罩模式 + PIN 锁屏 |

## 核心功能一览

```
资产核心                    人生小镇（RPG 层）
├── 仪表盘（净资产/结构）     ├── Hub 人生小镇（建筑入口）
├── 账户管理                  ├── 外出地图（五域生态 + 热力）
├── 记账 / 智能导入           ├── 微场景（框内写回忆/拍照/AI）
├── 趋势 / 预算 / 目标        ├── 人生馆 / 温馨小屋
├── 日历现金流                └── 习惯 / 任务（Life RPG）
└── 分析 / 设置
```

---

## 目标用户

- **主用户**：注重隐私、希望自主管理财务数据的个人用户（25–40 岁，一二线城市）
- **早期采用者**：已有微信/支付宝导出习惯、愿意试用未签名 Beta 的朋友/社群
- **非目标用户（v1）**：需要多设备云同步、家庭共享账本、企业财务的团队

## 差异化

| 对比 | 随手记 / 鲨鱼记账 | VaultFlow |
|------|-------------------|-----------|
| 数据归属 | 云端账号 | 本机文件 |
| 体验调性 | 工具型报表 | 粉白小镇 + 资产仪表盘双轨 |
| AI | 平台内置 | 可选自配百炼 Key，无 Key 可离线使用 |
| 导入 | 平台绑定 | 多格式本地解析，含银行 PDF |

---

## 关键指标（Beta 阶段）

| 指标 | 定义 | 当前目标 |
|------|------|----------|
| 激活率 | 安装后完成「添加账户 + 导入首笔流水」 | ≥ 60% 内测用户 |
| 7 日留存 | 7 天内再次打开 App | ≥ 40% |
| 导入成功率 | 微信/支付宝文件一次解析成功 | ≥ 85% |
| 反馈响应 | 用户邮件反馈 48h 内回复 | 100% |

---

## 风险与限制

- 未 Apple / Windows 代码签名 → 首次安装需手动允许
- 无云同步 → 换机需手动备份 `Documents/VaultFlow/`
- 部分银行 PDF 版式解析失败
- 浏览器模式与桌面版数据不互通
- AI 功能依赖用户自配 API Key
