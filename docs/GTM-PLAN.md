# VaultFlow Go-to-Market 计划

> 版本：Beta GTM v1 · 日期：2026-07-09 · 阶段：内测 → 公开发布

---

## 1. 执行摘要

VaultFlow 以 **「本地优先 + 人生小镇」** 双差异化切入个人理财工具市场。GTM 策略采用 **社区驱动的产品_led增长（PLG）**，先通过小范围内测验证导入成功率与留存，再逐步扩大到隐私意识社群、独立开发者社区和生活方式 KOL 圈层。

**首发滩头市场（Beachhead）**：注重隐私的一二线城市个人用户，已有微信/支付宝账单导出习惯，愿意试用 Beta 桌面 App。

---

## 2. 目标市场与 ICP

### 2.1 Ideal Customer Profile

| 维度 | 描述 |
|------|------|
| **人口** | 25–40 岁，中文用户，一二线城市 |
| **行为** | 使用 2+ 金融账户；定期导出微信/支付宝账单；对云记账有顾虑 |
| **痛点** | 数据分散、趋势看不清、不想注册/上传账单 |
| **技术接受度** | 可完成 dmg/exe 安装；可接受网盘下载 Beta |
| **情感需求** | 希望财务工具「好看、有生活感」，而非冷冰冰报表 |

### 2.2 非目标（v1 GTM 不投）

- 企业财务团队
- 需要实时家庭共享账本的用户
- 不愿安装桌面软件、只要手机 App 的用户

### 2.3 市场规模（粗略）

| 层级 | 估算逻辑 | 规模 |
|------|----------|------|
| TAM | 中国个人记账/理财 App 用户 | ~2 亿 |
| SAM | 注重隐私 + 愿意用桌面工具 | ~500 万 |
| SOM（12 个月） | 内测→公开，无营销预算 PLG | 1,000–5,000 活跃用户 |

## 3. 定位与核心信息

### 3.1 定位声明

> 对于注重隐私的个人用户，VaultFlow 是一款本地优先的资产可视化工具。与随手记、鲨鱼记账等云记账 App 不同，VaultFlow 把数据留在你的电脑上，并用人生小镇让记账变成有温度的生活记录。

### 3.2 核心信息层级

| 层级 | 信息 |
|------|------|
| **一句话** | 你的资产，只住在你的电脑里。 |
| **支撑点 1** | 微信/支付宝/银行账单，本地智能导入 |
| **支撑点 2** | 净资产趋势、预算、目标，一屏看清 |
| **支撑点 3** | 人生小镇：记账 × 回忆，五域生态地图 |
| **情感钩子** | 不是填表，是经营你的人生小镇 |

### 3.3 竞品差异化（Battlecard 简版）

| 维度 | 随手记/鲨鱼记账 | Excel/Notion 自建 | VaultFlow |
|------|----------------|-------------------|-----------|
| 隐私 | 云端 | 自控 | 本地文件，自控 |
| 上手 | 快（注册即用） | 慢（自建） | 中（安装+导入） |
| 导入 | 平台绑定 | 手动 | 多格式本地解析 |
| 体验 | 工具报表 | 灵活但丑 | 仪表盘 + 游戏化 |
| 跨设备 | 强 | 看方案 | 弱（v1） |
| 价格 | 免费+订阅 | 免费 | 免费（内测） |

**应对「没有云同步」**：诚实告知，强调备份文件夹即可迁移；目标用户更看重隐私而非便利。

**应对「未签名安装麻烦」**：提供图文安装指引；正式版争取代码签名。

```
优质内测体验 → 用户主动推荐朋友
      ↑                    ↓
  快速修复反馈 ← 导入成功看到趋势曲线

  回忆/小镇惊喜感 ← 持续使用 7 天+
```

**当前瓶颈**：安装摩擦（未签名）+ 无云同步。飞轮启动靠私域高信任用户，不靠大规模投放。

## 5. 发布计划

### 5.1 阶段划分

#### Phase 0 — 内测准备 ✅（已完成）

- [x] Beta 打包流程（`npm run app:build:mac`）
- [x] 内测文档（`BETA.md`）
- [x] 反馈邮箱

#### Phase 1 — 封闭内测（当前，4 周）

| 周 | 动作 |
|----|------|
| W1 | 分发 `1.0.0-beta.1` 给 10–15 人；收集安装/导入问题 |
| W2 | 发布 `beta.2`（导入修复）；扩至 30 人 |
| W3 | 收集 7 日留存数据；小镇体验定性访谈（5 人） |
| W4 | 复盘 Go/No-Go；决定是否进入公开 Beta |

**发布日清单**：
- 网盘链接 + 版本号 + 更新说明
- 复制 `BETA.md` 第八节短文案到群
- 强调：请勿在群里发账单

#### Phase 2 — 公开 Beta（+4–8 周）

- GitHub Releases 公开发布 dmg/exe
- 少数派/V2EX 投稿（_local-first 个人理财工具_
- 制作 60 秒演示 GIF（导入→趋势→小镇）
- 建立 FAQ（安装、备份、导入失败）

#### Phase 3 — 1.0 正式版（+8–12 周）

- 代码签名（预算允许）
- 产品主页（单页：下载 + 隐私承诺 + 截图）
- 考虑定价：免费核心 + 可选赞助/Pro（云同步预留，非 v1）

### 5.2 上市日（Launch Day）活动

1. 发布安装包 + 更新日志
2. 社群同步短文案
3. 监控反馈邮箱前 48 小时
4. 准备「导入失败」快速响应模板

## 6. 成功指标（KPI）

### 6.1 Beta KPI

| 指标 | 定义 | 目标 | 测量方式 |
|------|------|------|----------|
| 激活率 | 安装后完成账户+导入 | ≥ 60% | 内测问卷 |
| 导入成功率 | 首份账单一次解析成功 | ≥ 85% | 反馈统计 |
| 7 日留存 | 7 天内再次打开 | ≥ 40% | 自愿上报/问卷 |
| NPS | 净推荐值 | ≥ 30 | 内测结束调研 |
| 崩溃率 | 启动/导入/保存崩溃 | < 1% | 用户反馈 |

### 6.2 公开 Beta KPI

| 指标 | 目标 |
|------|------|
| 月下载量 | 500+ |
| 有效激活 | 200+ |
| 社群推荐占比 | ≥ 50% 新用户来源 |

### 6.3 北极星指标（North Star）

**周活跃记账用户数（WAM）**：本周内至少录入 1 笔交易或完成 1 次导入的用户数。

**输入指标**：
- 新用户完成首次导入率
- 人均周记账笔数
- 小镇页面访问占比（验证游戏化价值）

## 8. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 安装门槛高（未签名） | 高 | 激活率低 | 图文指引；正式版签名 |

| 竞品模仿本地导入 | 低 | 差异化减弱 | 强化小镇体验壁垒 |
